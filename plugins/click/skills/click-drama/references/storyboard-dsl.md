# 分镜脚本 DSL

这份语法用于 Click 的**单场景分镜文本**，也由项目导入接口解析。项目级 `.md` / `.txt` 文件还包含分集标题与场景标题；那些标题是定位场景的外壳，不属于下面的镜头 DSL。

写项目导入文件时，先从目标分镜项目导出模板，原样保留分集与场景标题，只编辑每个场景标题下面的镜头块。

## 默认格式

```text
第1集 银子与人心

[1-1] 内 - 朝廷大厅 - 白天

1:
景别: 全景
运镜: 缓推
机位: 仰拍
灯光: 逆光
灯光位置: 正门方向高位
时长: 8s
画面描述: @朝廷大厅 内，@崇祯皇帝 独自站在御阶前，背影逆光，面对分列两侧、低头屏息的群臣。殿门外天色阴沉，冷风卷动门帘，镜头沿中轴缓慢推进。
视频内容: 0s-2s，从群臣队列后方沿中轴线缓慢推进；2s-5s，推进至群臣中段；5s-8s，停在皇帝与群臣之间。@崇祯皇帝 说：「李自成的大军已经逼近京师，诸位受大明俸禄多年。今日，朕请皇亲国戚、文武百官捐银助饷。」【音色：男声，中年，克制但透着疲惫。】

+:
景别: 特写
运镜: 固定
机位: 平视
灯光: 侧光
灯光位置: 人物左前方
时长: 4.5秒
画面描述: @户部尚书 低头攥紧袖口，额角渗汗，身后群臣保持沉默。
视频内容: 0s-2s，手指在袖中收紧；2s-4.5s，他抬眼又迅速避开 @崇祯皇帝 的视线。
```

在单场景编辑器里，只粘贴从 `1:` 开始的镜头块，不要带“第1集”或 `[1-1]` 标题。

## 镜头标记

- `1:`、`2:` 等正整数是镜头标记。
- `+:` 明确创建新镜头。不要用 `0:`、负数或小数当镜头标记。

半角 `:` 和全角 `：` 都能解析。推荐统一使用半角冒号，保持文本一致。

## 字段

每个镜头支持以下字段，顺序自由，每个字段最多出现一次：

| 字段 | 写法与含义 |
|---|---|
| `景别` | 使用编辑器候选的中文值，如大远景、远景、全景、中景、近景、特写、大特写。不要默认写存储层枚举 `full_shot`。 |
| `运镜` | 使用编辑器候选的中文值，如固定、推进、缓推、拉远、左摇、跟拍、手持。不要默认写 `slow_push_in`。 |
| `机位` | 优先使用编辑器候选，如平视、俯拍、仰拍、荷兰角。 |
| `灯光` | 优先使用编辑器候选，如顺光、侧光、逆光、顶光、自然光、柔光。 |
| `灯光位置` | 自由文本，写光源相对主体或场景的位置。 |
| `时长` | 必须是大于 0 的数字，可带 `s` 或 `秒`，支持小数，如 `8s`、`4.5秒`、`3.5`。具体模型是否支持该时长在生成步骤校验。 |
| `画面描述` | 单镜自洽的可见画面：主体、动作过程、场景锚点、构图、镜头和光影。使用项目素材的准确 `@名称`。 |
| `视频内容` | 覆盖完整时长的动态过程：分段时间、动作推进、镜头变化、对白/音效时机和结尾状态。 |
| `备注` | 只放不应进入生成提示词的流程性说明。没有这类说明就省略整个字段。 |

字段可以省略，但为了让后续生成可控，默认把除 `备注` 外的八个字段写全。未知字段不会写入镜头；不要自创字段名。

### 备注边界

判断一句话是否属于 `备注`：如果视频模型看见它后可能改变构图、主体、表演、动作、镜头、灯光、环境或声音，就不要写在备注里。

- “推进速度缓慢、沉重”“大殿要有压抑感”“地面有泥脚印”“表演保持克制”都会影响成片，移入 `画面描述` 或 `视频内容`。
- “对应客户审片表第 12 条”“史料来源待制片确认”这类不应改变生成结果的流程信息才可以写在 `备注`。
- 无流程性备注时直接省略，避免用空备注承载生成提示词。

## 多行正文与转义

字段值可以换行。字段标题之后的普通行会继续归入当前字段，开头与结尾的空行会被裁掉，中间空行保留：

```text
视频内容:
0s-2s，固定低机位，人物进入画面。
2s-5s，镜头缓慢推进。
5s-8s，人物说完对白，镜头停住。
```

如果字段正文中的某一行本身长得像 DSL 结构，例如 `2:`、`+:` 或 `备注: 这是画面里的字`，在行首加一个反斜杠：

```text
画面描述:
墙上的板书写着：
\2:
\备注: 这是画面里的字
```

解析时只会去掉这一层转义。字段之外的孤立正文、字段之前的内容、重复字段和无效镜头标记属于语法错误。

## 写完后的检查

1. 每个镜头都有合法镜头标记，已有镜头沿用导出编号，新增镜头用 `+:`。
2. 只使用九个固定字段；景别、运镜优先用编辑器中文候选。
3. `时长` 为正数，`视频内容` 的时间段覆盖完整时长。
4. `画面描述` 中的 `@名称` 与项目素材目录完全一致，单镜脱离上下镜也能看懂。
5. 会影响成片的内容不留在 `备注`。
